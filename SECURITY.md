# Security policy

## Supported versions

Security fixes go into the latest release only. Before you report, upgrade to the newest version on npm and check that the problem is still there.

## Report a vulnerability

Report it privately through the [vulnerability reporting form](https://github.com/d2a8k3u/typoseek/security/advisories/new) on GitHub. Only you and the maintainers see the report. Do not open a public issue, pull request or discussion about it.

Include the typoseek version, the runtime and its version, and the smallest code and input that show the problem.
